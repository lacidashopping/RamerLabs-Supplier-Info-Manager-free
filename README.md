== Description ==

RamerLabs Supplier Info Manager is a lightweight utility designed to help e-commerce store managers track wholesale product costs, maintain explicit records of supplier profiles, and launch quick messaging avenues.

= Core Layout Features =
* **Logistics Ledger:** Track product names, source vendor verification links, cost logs, and active wholesale documentation data.
* **Direct Communication Triggers:** Launch instant, single-click communication strings to your vendors via custom WhatsApp and Telegram hooks.
* **Native Admin Integration:** Clean layout configurations that plug directly into the standard WordPress Tools interface hierarchy.

== Installation ==

1. Upload the `ramerlabs-supplier-info-manager` folder to the `/wp-content/plugins/` directory, or upload the custom `.zip` package directly through the WordPress Plugins dashboard screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Access the dashboard data management panels by navigating to **Tools** ➔ **Supplier Info**.

== Frequently Asked Questions ==

= Does this plugin collect external data tracking parameters? =
No. All database actions, entries, and supplier information logs are saved locally and securely entirely inside your native WordPress custom database tables.

= Where do I find the dashboard manager window? =
To respect standard core admin layout structures, the interface window is located under the **Tools** menu sub-panel.
